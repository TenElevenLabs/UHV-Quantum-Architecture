Baseline Measurement Standards
 
The following figures define the acceptance criteria for a qualified µUHV package:
• Base Pressure: < 10⁻¹⁰ mbar (Target: 10⁻¹¹ mbar)
• Helium Leak Rate: < 5 × 10⁻¹⁵ mbar·L/s (Measured via accumulation method)
• Cryocooler Thermal Load: ~70.1 mW at 77 K
• YBCO Coil Ohmic Loss: < 8 nW
• Analog QEC Gauge Power: < 80 µW sustained
• Residual Acceleration: < 1.0 µg/√Hz (1–100 Hz band)
